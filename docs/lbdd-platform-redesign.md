## 3. 设计原则

1. 离线优先 = Pages/localhost 全功能;`navigator.storage.persist()`
   + "上次导出"指示器
2. 工作流连续性 > 功能堆叠
3. **命中表 = 分子 × 轮次稀疏矩阵**:每轮贡献类型化分数列
   (量纲/参数在列头 tooltip);排序只在同列内;任何融合分(共识/
   组合)都是**显式命名的融合列**,公式进 tooltip——组合分数也不
   例外(评审 2 抓住了 v0.2 的自相矛盾)
4. 零学习成本下限
5. 绞杀者改造:检查器先行组件化,旧 UI 并存且**对项目状态只读**
   (绞杀者双写规则,评审 2 风险 7)

## 4. 数据模型

### 4.1 分子身份(评审 2 补两洞)

- **molId** = hash(libraryId, **记录序号 ordinal**, rawRecord)——
  同库内重复原始记录不再碰撞
- **structureKey**(InChIKey 优先):视图级去重;**M0 探针验证
  vendored 构建是否含 InChI 支持**,无则退规范化 SMILES(漂移仅
  降级去重效果,不孤儿化 pin)
- **库重导入 = 版本操作**:经 structureKey(退 ID/名称列)映射旧
  molId→新 molId,出对账报告("1987 结转,11 结构变更,2 移除"),
  被移除分子的 pin 以孤儿态可见不静默丢弃;对账发 IdentityChanged/
  Merged/Split **命令**(进命令日志),受影响单元格翻 Stale 态
- **structureKey 归一化层级显式定稿**(Fable a2):盐基/互变异构/
  立体未定vs已定 的 InChIKey 层语义选一层并写死——否则同 SDF 两人
  数出不同行数
- **合成库身份(M3 前只留钩子)**:生成分子 molId =
  hash(parentMolId, attachmentIdx, fragmentId, fragmentSetVersion,
  productCanonical)——一段话现在写好,M3 免 schema 迁移

### 4.2 轮次 DAG + 单元格状态(评审 2 风险 2/3)

- 轮 = { 输入集, 查询, 参数, 输出 };下钻默认交互,生成子节点;
  左栏血缘缩进树
- **单元格六态**(Fable:身份对账需要第六态):`NotInInput |
  Scored(v) | BelowThreshold(v) | Failed(reason) | Pending |
  **Stale**(对账后结构已被取代——重导入修正同 ID 行时,旧分不能
  继续顶着有效态显示)——空格语义不明是排序/融合/导出的静默错误源
- **甄别 = 分子级覆盖层 + 溯源 + DAG 前向传播 + 轮内可覆写**(Fable
  a1:纯分子级无法解释"为何被杀",纯单元格级让兄弟分支复活一切
  已杀分子;两者单独都不对)
- **确定性结果也带版本戳缓存**(Fable a5:重算只作戳不匹配的回退
  ——否则项目加载变成计算作业,20 万分子库打开即卡);列惰性物化
- **整输入集存分**(~2.4MB @ 10⁴×30 轮×2 列):阈值变**视图过滤
  而非存储事实**(0.6→0.5 免重跑),下钻非破坏

### 4.3 持久化四层(评审 2 细化)

| 层 | 内容 | 策略 |
|---|---|---|
| L1 事实 | 输入/查询/参数/pin/备注/molId/DAG 结构 | 始终存储 |
| L2 派生-确定 | 指纹/描述符/QED/警示 | 重算(可缓存) |
| L3 结果-随机 | 每分子最优姿态(+top-k)+ 分数,**带 seed/engineVersion/rdkitVersion/位点权重/对齐参数**(flex 结果的完整输入谱系) | 存储 |
| L3′ 构象缓存 | 全构象系综,内容寻址 (structureKey, embedParams, seed, rdkitVersion) 跨轮共享 | 可驱逐缓存;项目导出默认不含 |

- **种子**:每任务 seed = hash(roundSeed, molId, confIdx)——与
  worker 数/调度序无关;wasm 确定性 + Rust libm 内联 ⟹ 跨机逐位
  可复现,入 CI 断言
- 加载遇版本不一致 → 显式警告不静默重算
- **多标签**:Web Locks API(navigator.locks.request)做互斥
  (Safari 15.4+;WebKit 进 CI 矩阵,不只 Chromium——Fable d1),
  BroadcastChannel 仅通知只读标签
- **持久性硬话术**(Fable d1:IndexedDB 逐出是耐久性故事本身):
  persist() 调用并**向用户呈现结果**(可能被静默拒绝);storage.
  estimate() 轮询阈值告警;命令日志按节拍**自动导出到文件**
  (File System Access API 可用则用,否则下载催促);PWA 可安装性
  (把 Safari ITP 的 7 天无交互删除钟赶下台);启动检测"DB 消失了"
  并明说,不显示空项目装没事

### 4.4 命令日志(评审 2 风险 6)

项目 = append-only 命令日志 + 快照。撤销覆盖甄别与 DAG 结构编辑;
计算结果永不"撤销"只隐藏;自动保存天然增量;成功判据的会话回放
几乎免费。M0 必须定稿:**快照节拍**(Fable a7:两周 5 万条命令
是常态,无节拍则不可测)与**带子轮的撤销语义**(拒绝并解释 vs
级联——纯 M2 发现 = 太晚)。

### 4.5 视图域规则(评审 2 风险 5)

- 行 = 当前选中 DAG 节点的输出集
- 列 = 该节点祖先路径上的分数列;兄弟分支可从列选择器加入
- 工作集全局:他分支 pin 的行折叠显示 "pinned elsewhere (N)"
- 排除全局且向下游传播,常驻 "N excluded" 徽标(不做分支级排除)
- **DAG 修剪与前沿视图**(Fable a3:40 轮后 40×N 列是横向滚动灾难;
  虚拟化管行不管列):轮次命名/死分支归档折叠/"frontier" 只显叶轮;
  列虚拟化
- **融合策略与不可通约警示**(Fable a4):秩融合回避量纲但掩盖
  "一模 12 命中一模 4000 命中";归一化策略 + 融合列头明示混合了
  不可比模式

## 7. 片段探索器算力预算(评审 2 §d 全盘采纳)

**分级漏斗**(drug-like ~25–35 重原子,4-worker 无共享内存):

| 级 | 工作 | CPU | 墙钟 |
|---|---|---|---|
| A 枚举+过滤 | ≤400 产物,价键/立体/质子化/合理性 | ~1–2s | ~1–2s |
| B 粗 3D | ~250 产物 × 10 构象(转子自适应 5–15),**刚性**叠合 | ~110s | **~25–30s,流式出结果** |
| C 精化 | top-30 产物扩 30–50 构象,刚性 | ~50s | ~12–15s |
| D Flex | top-10 从最优刚性姿态柔性叠合 | ~10–30s | ~5–10s |

**合计 ~45–60s 墙钟**,5s 起流式可见——"深操作"可接受预算,
带进度条与取消。

**硬顶**:每次运行单取代点(多取代组合爆炸另配预算 UI)/片段集
≤150(超出须预筛或接受耗时警告)/产物 ≤400 过滤后/转子 >10 跳过
或标记/flex 仅 top-K(默认 10 上限 50)/**运行前估时**(启动微基准
缓存, "~N 产物 × M 构象 ≈ X s")/结果流式入表(Pending→Scored
正是单元格状态模型的受益处)。

## 8. 测试策略(按真实回归收益排序,Fable e)

1. **命令序列性质测试**(最高收益,Rust proptest 免浏览器):随机
   合法命令流 → 断言 `replay(log) == snapshot + replay(tail)`、前缀
   组合性、undo/redo 往返、DAG 无环、单元格状态机只走合法迁移、
   对账幂等且可交换
2. **金标项目夹具**:每个发布 schema 版本提交一个真实导出项目,
   CI 加载投影状态 diff;RDKit 金标输出(canonical SMILES/指纹位/
   种子构象)按 vendored 构建钉死——上游升级是可见 diff 不是玄学
3. **窄域模糊**:导入器(SDF/SMILES/CSV→身份模型)与日志/快照
   反序列化——截断/损坏必须清晰报错+部分恢复,不是空项目;
   SMILES 打进 WASM 边界找 RDKit abort(会杀 worker)
4. **混沌**:会话中删 IndexedDB;批处理中 terminate worker 断言
   重派且结果一致;双标签锤 Web Locks;同种子 3D 作业跨
   Chromium/Firefox/WebKit(Playwright)断言逐位一致(漂移=种子 bug)
5. 单元测试(最低收益,开发速度用)
